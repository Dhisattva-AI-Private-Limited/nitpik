NitPik

Nitpick any page. One script tag.

Reviewers hover any element, click, and leave a comment pinned to that exact spot. You get the selector, the text and the feedback, ready to paste into your tracker or your AI assistant.

<script src="https://unpkg.com/nitpik"></script>

The problem

Your stakeholders screenshot and say “the thing feels wrong”

“Can you make that bit a little more... you know. Also the other thing, near the top.”

Screenshots lose the context. Chat threads lose the element. You end up guessing which button, which heading, which card. NitPik attaches every comment to the exact element it is about.

How it works

Three steps. No account, no build step.

Step 1

Add one script tag

Paste it before </body>. NitPik starts by itself and adds nothing else to your markup.

Step 2

Hover any element

A small comment trigger appears on headings, cards, buttons, images and more. Skip any part with data-nitpik-ignore.

Step 3

Click and comment

Type the feedback. NitPik records the CSS selector, the DOM path and the element text alongside it.

For vibe coders

You built it with AI. Now get real human feedback.

Your assistant can ship a page in minutes. Knowing what a person thinks of it takes longer. NitPik closes the loop: the MCP server lets your AI coding assistant add the script to a page, read the comments back, and strip the script when review is done.

nitpik_inject

Adds the script tag to an HTML file so reviewers can start commenting.

nitpik_read

Reads the saved comments, each with its selector, so the assistant can fix the right element.

nitpik_strip

Removes the script tag when the review round is finished.

npx nitpik-mcp

Register it as a stdio MCP server in your assistant. The repo also ships a skill that walks it through the setup.

Output modes

Send feedback wherever it needs to go.

Clipboard

The default. Each comment is copied as Markdown, ready to paste into a chat, an issue or a prompt.

data-mode="clipboard"

Collect

Comments pile up in the browser. Export them all as a Markdown or JSON file in one click.

data-mode="collect"

Callback

Handle each comment in your own code and send it to any tracker or backend.

NitPik.on('comment', fn)

Install

One script tag.

That is the whole setup. Add attributes to change the mode, the accent colour or the reviewer name.

<script src="https://unpkg.com/nitpik"
        data-mode="clipboard"
        data-color="#F59E0B"></script>

Prefer a package manager?

npm install nitpik
