NitPik

Nitpick any page. One script tag.

Reviewers hover any element on your web page, click, and leave a comment pinned to that exact spot. You get the CSS selector, the DOM path, and the feedback — ready to paste into your tracker or AI assistant.

The problem

Your stakeholders screenshot and say “the thing feels wrong”

“Can you make that bit a little more… you know. Also the other thing, near the top.”

Screenshots lose the context. Chat threads lose the element. You end up guessing which button, which heading, which card. NitPik attaches every comment to the exact element it is about.

How it works

Three steps. No account, no build step.

Step 1

Add one script tag

Paste it before </body>. NitPik starts by itself and adds nothing to your markup.

Step 2

Hover any element

A small trigger appears on headings, sections, cards, buttons, images, and more. Smart tree detection finds the right level.

Step 3

Click and comment

Type the feedback. NitPik records the CSS selector, the DOM path, and the element text alongside it.

Implementation

The entire setup

Add one line to your HTML. That is the whole integration.

Output modes

Send feedback wherever it needs to go.

Clipboard

The default. Each comment is copied as Markdown, ready to paste into a chat, an issue, or a prompt.

data-mode="clipboard"

Collect

Comments pile up in the browser. Export them all as a Markdown or JSON file in one click.

data-mode="collect"

Callback / API

Handle each comment in your own code or POST to any endpoint. Send feedback to your tracker or backend.

NitPik.on('comment', fn)

For AI-assisted development

Your AI assistant adds NitPik in one prompt.

Ship a page with AI, then get real human feedback on it. The MCP server lets your coding assistant inject the script, read comments back, and strip it when the review is done.

nitpik_inject

Adds the script tag to an HTML file so reviewers can start commenting.

nitpik_read

Reads saved comments with their CSS selectors, so the assistant fixes the right element.

nitpik_strip

Removes the script tag when the review round is finished. Clean output.

# Register as MCP server in your AI assistant

Install

One script tag. That is the whole setup.

Add attributes to change the mode, the accent colour, or the reviewer name.

<script src="https://cdn.jsdelivr.net/npm/nitpik"
  data-mode="clipboard"
  data-color="#F59E0B"></script>

Prefer a package manager?

npm install nitpik
import NitPik from 'nitpik'
NitPik.init({ mode: 'collect' })
